# Research: Competing Scientific Hypotheses

## Problem

Several hypotheses explain the first observation.

## Governed analysis

OURD names objects, variables, assumptions, and relations. IURM selects a discriminating experiment. IEPS records provenance, measurement quality, counterexamples, and limitations. CFEL updates support without pretending that one failed prediction proves every alternative.

## Evidence status

**Theoretical teaching example.** It demonstrates hypothesis bookkeeping rather than a domain-specific scientific result.

## Lesson

A good experiment is valuable because plausible alternatives predict different observable outcomes.
