# Engineering: Controller Oscillation

## Problem

A temperature controller repeatedly overshoots and undershoots its setpoint.

## Governed analysis

OURD maps controller, sensor, process, delay, gain, setpoint, disturbance, and measurement. IURM varies gain while holding plant conditions stable. EON bounds any real parameter change to an authorized system and verification plan.

## Evidence status

**Theoretical teaching example.** The browser fixture is not a plant model and grants no control-system authority.

## Lesson

The architecture separates diagnostic experiments from permission to alter a real controller.
