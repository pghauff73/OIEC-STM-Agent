# Write a Report

## Goal

Produce a report whose claims are traceable to sources, whose inferences are labeled, and whose limitations remain visible.

## Learning route

Complete T03 Evidence, T07 EON, and T11 A/B Evidence.

## Method

Separate the report into source facts, calculations, observations, interpretations, proposals, and unresolved claims. Bind the writing session to the intended report path and preserve citations or repository references.

## Misconception to avoid

Fluent prose does not increase evidence quality. A model can improve organization and wording without becoming the authority for factual claims.

## Safe completion condition

Every material claim has named evidence or an explicit limitation, and generated wording does not overstate implementation, testing, approval, certification, or release status.
