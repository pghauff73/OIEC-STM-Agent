# IURM

## What you will learn

You will define a baseline, preserve invariants, vary one useful dimension, and name the observation that would discriminate between hypotheses.

## Everyday analogy

If bread is dense, changing flour, water, yeast, temperature, and timing together may produce a different loaf but teaches little about the cause. A controlled experiment changes one justified variable.

## New vocabulary

**IURM** means Invariant-Uncertainty-Response Modeling. An **invariant** must remain true. A **baseline** is the fixed comparison state. A **response** is the measured observation.

## Command or interaction

Select one lamp hypothesis in the sandbox, choose one test, and state what stays invariant before revealing the observation.

## Expected output

The experiment record names one varied dimension, the preserved baseline, the expected discriminating outcomes, and the observed response.

## What just happened?

IURM converted uncertainty into a controlled evidence request. It may also abstain when no dimension can be isolated safely.

## Try changing this

Design a parser experiment that changes one precedence rule while holding the test corpus, parser version, and all unrelated grammar rules constant.

## Common mistake

Changing many coupled dimensions and observing improvement does not establish which change caused the result.
