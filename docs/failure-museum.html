Refusal quality is part of system quality.

These examples teach why the architecture stops, what invariant was protected, and which evidence could justify a different next step.

DETERMINISTIC REFUSAL

Enable write mode without a path

Why it stopped: Bounded write mode requires at least one explicit write path.

Evidence needed: A human-declared path or pattern defining the permitted proposal boundary.

DETERMINISTIC REFUSAL

Combine bounded write mode with yolo

Why it stopped: Bounded write mode never bypasses exact-candidate review.

Evidence needed: Use a separately reviewed authority manifest when broader approval policy is intended.

DETERMINISTIC REFUSAL

Change two adaptation dimensions

Why it stopped: The adaptation record permits one controlled dimension.

Evidence needed: Create a new experiment plan that represents and tests the coupled change explicitly.

DETERMINISTIC REFUSAL

Promote an untested candidate

Why it stopped: Canonical promotion requires the declared qualification evidence.

Evidence needed: Complete the candidate-versus-baseline evidence contract and regression checks.
